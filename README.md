# 💛 Nirvana - Polish Fanpage

Nieoficjalna polska strona poświęcona zespołowi **Nirvana** — od pierwszych prób w Aberdeen w 1987 roku po kwiecień 1994.

🌐 **Docelowy adres:** [https://nirvana.nsv.pl](https://nirvana.nsv.pl)

---

## O projekcie

Statyczna strona w HTML, stylowana Tailwind CSS, publikowana z GitHuba w Cloudflare Pages. Konstrukcja i stack są bliźniacze wobec projektu [typeonegative](../typeonegative), różni się motyw: żółć smileya (`#f5d020`) na prawie czarnym tle.

## Technologie

* HTML5
* Tailwind CSS 3.4.17 (Tailwind CLI)
* Cloudflare Pages (hosting i deployment)
* Fonty self-hosted: **Anton** (nagłówki) i **Oswald** (tekst), subsety latin i latin-ext

## Build

```bash
npm ci          # albo npm install
npm run build   # generuje css/style.css
npm run watch   # tryb deweloperski
```

## Źródła treści

Część materiałów opracowano na podstawie archiwalnego serwisu **Total Nirvana!** Marcina Harasia (2004), dostępnego w Internet Archive:
<https://web.archive.org/web/20041206095953/http://www.tn.px.pl/>

Teksty na stronie pisane są od zera — serwis źródłowy służy jako źródło faktów i inspiracja układu działów, nie jako materiał do przeklejania. Teksty utworów, tłumaczenia i tabulatury nie są publikowane.
